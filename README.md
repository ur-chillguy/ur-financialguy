# ur.financialguy

Aplikasi keuangan pribadi untuk mencatat arus kas, memantau kekayaan bersih, dan menghitung rencana besar: dana darurat, simulasi KPR, tujuan keuangan, monitor investasi, rebalancing, sampai persiapan pensiun dengan aturan 4%.

- Halaman produk: `index.html`
- App: `app/index.html` (satu file, tanpa backend; data tersimpan di browser pengguna, bisa backup dan pulihkan lewat file JSON)
- PWA: `manifest.webmanifest`, `sw.js`, `icons/` (bisa dipasang ke layar utama dan dibuka offline)
- Coba dengan data contoh: buka `app/?demo=1`

Modul: Ringkasan & cek kesehatan keuangan, Piramida keuangan, Arus kas, Kekayaan bersih, Dana darurat, Tujuan keuangan, Simulasi KPR, Monitor investasi, Rebalancing, Persiapan pensiun, Glosarium.

Alat bantu hitung dan pencatatan, bukan nasihat keuangan profesional.
